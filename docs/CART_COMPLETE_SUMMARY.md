## 🆘 Need Help?

### Quick Troubleshooting

| Problem | Check | Solution |
|---------|-------|----------|
| Cannot find product | `npx prisma studio` | Verify product exists & isActive=true |
| Insufficient stock | Product table | Update stock value |
| Cart not found | Headers | Use consistent X-Session-Id |
| Unauthorized | JWT token | Get fresh token from login |
| Slow response | Metrics endpoint | Check cache hit rate |
